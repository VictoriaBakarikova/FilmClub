# 🎬 FilmClub

**FilmClub** is a web-based platform for discovering, discussing, and cataloging your favorite films. Built with Django and designed for clarity and scalability, it offers user authentication, personalized film pages, and a cinematic interface.

---

## 🚀 Features

- User sign-up and login
- Responsive and aesthetic UI with custom templates
- Film catalog integration with admin panel
- Secure environment variable management
- Docker-based development for consistency

---

## 🧰 Tech Stack

- **Backend:** Django (Python)
- **Frontend:** HTML, CSS, Bootstrap
- **Environment Management:** `dotenv`, Docker
- **Authentication:** Django's built-in auth system
- **Dev Tools:** PyCharm, Docker Compose
